# ⛸️ Аналитика фигурного катания

Веб-приложение для анализа результатов соревнований по фигурному катанию из PDF файлов и управления базой данных фигуристов.

## 🚀 Возможности

- **Парсинг PDF файлов** - Автоматическое извлечение данных о фигуристах, элементах, компонентах и оценках из PDF файлов с результатами соревнований
- **База данных фигуристов** - Хранение данных в IndexedDB для быстрого доступа и анализа
- **Поиск фигуристов** - Поиск по имени или фамилии с автодополнением
- **Статистика** - Анализ результатов, средние баллы, сравнение фигуристов
- **Экспорт/Импорт** - Сохранение и загрузка данных в формате JSON

## 📋 Структура проекта

```
├── index.html          # Главная страница с навигацией
├── script.js           # Основная логика приложения и парсинг PDF
├── database.js         # Модуль работы с IndexedDB
├── style.css           # Стили приложения
├── DATABASE_GUIDE.md   # Руководство по базе данных
└── README.md           # Документация проекта
```

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Redji90/figure_scating_web.git
cd figure_scating_web
```

2. Откройте `index.html` в браузере

Приложение работает полностью локально, не требует установки зависимостей или сервера.

## 💻 Использование

### Загрузка PDF

1. Нажмите на карточку "Загрузка PDF" на главной странице
2. Перетащите PDF файл с результатами соревнований или выберите файл
3. Дождитесь автоматического анализа
4. Сохраните результаты в базу данных

### Поиск фигуристов

1. Нажмите на карточку "Поиск фигуристов"
2. Введите минимум 3 символа имени или фамилии
3. Выберите фигуриста из списка
4. Просмотрите статистику и все соревнования

## 📊 База данных

Приложение использует IndexedDB для хранения данных локально в браузере. Все данные хранятся на вашем компьютере и не передаются на сервер.

Подробнее о структуре базы данных и возможностях миграции на облачное хранилище см. [DATABASE_GUIDE.md](DATABASE_GUIDE.md).

## 🔧 Разработка

### Структура данных

- **Соревнования** - Информация о соревнованиях
- **Фигуристы** - Список всех фигуристов
- **Элементы** - Выполненные элементы с оценками
- **Компоненты** - Программные компоненты с оценками судей

### Расширение функциональности

Для добавления новых функций:
1. Модифицируйте парсер в `script.js` для обработки новых форматов
2. Обновите схему базы данных в `database.js` при необходимости
3. Добавьте новые страницы в `index.html`
