# Информация о получении данных о результатах соревнований

## Текущая ситуация

**Официальных API нет** для получения результатов соревнований от:
- **ISU** (Международный союз конькобежцев)
- **ФФККР** (Федерация фигурного катания на коньках России)

## Доступные способы получения данных

### 1. Парсинг HTML страниц ISU ✅ (частично реализовано)

**Текущая реализация:**
- Функция `fetchAndParseISUResults()` в `script.js`
- Парсинг таблиц результатов с сайта ISU
- Использование CORS-прокси для обхода ограничений

**Ограничения:**
- Требуется CORS-прокси (может быть нестабильным)
- Структура HTML может изменяться
- Нет автоматического обновления данных

**Улучшения:**
- Добавить парсинг детальных результатов (элементы, компоненты)
- Реализовать кэширование данных
- Добавить обработку ошибок и повторные попытки

### 2. Парсинг PDF файлов ✅ (полностью реализовано)

**Текущая реализация:**
- Парсинг PDF с результатами соревнований
- Поддержка форматов ISU и российских соревнований
- Извлечение элементов, компонентов, оценок судей

**Преимущества:**
- Полные данные из официальных протоколов
- Детальная информация по каждому элементу

**Недостатки:**
- Требуется ручная загрузка файлов
- Нет автоматического обновления

### 3. Парсинг официальных сайтов

#### ISU (isu.org)
- **URL структура:** `https://www.isu.org/figure-skating/events/figure-skating-calendar/eventdetail/...`
- **Формат данных:** HTML таблицы
- **Доступность:** Публичный доступ

#### ФФККР (fsrussia.ru)
- **URL структура:** `https://fsrussia.ru/otchety/...`
- **Формат данных:** PDF файлы и HTML страницы
- **Доступность:** Публичный доступ

### 4. Альтернативные источники

#### Специализированные сайты:
- **Olympteka.ru** - результаты соревнований с таблицами
- **SkatingScores.com** - база данных результатов (может иметь API)
- **Golden Skate** - форумы и обсуждения

#### Социальные сети:
- **Telegram канал ФФККР:** [t.me/ruskating](https://t.me/ruskating)
- **ISU Events App** - мобильное приложение с результатами

## Рекомендации по реализации

### Вариант 1: Улучшение парсинга HTML (рекомендуется)

```javascript
// Пример улучшенной функции парсинга ISU результатов
async function fetchISUResultsDetailed(eventId) {
    // 1. Получить список соревнований
    // 2. Для каждого соревнования получить детальные результаты
    // 3. Парсить элементы и компоненты из HTML
    // 4. Сохранить в базу данных
}
```

**Преимущества:**
- Автоматическое обновление данных
- Не требует ручной загрузки файлов
- Можно настроить регулярное обновление

**Недостатки:**
- Зависимость от структуры HTML
- Может потребоваться обработка CORS

### Вариант 2: Создание собственного API сервера

**Архитектура:**
```
[Браузер] -> [Backend Server] -> [Парсинг ISU/ФФККР] -> [База данных] -> [API]
```

**Преимущества:**
- Полный контроль над данными
- Кэширование и оптимизация
- Можно предоставить API другим пользователям

**Недостатки:**
- Требуется сервер
- Необходимо поддерживать парсеры

### Вариант 3: Интеграция с существующими базами данных

**Возможные источники:**
- **SkatingScores.com** - может иметь API или экспорт данных
- **Open Source проекты** - GitHub репозитории с данными

## Технические детали

### CORS и обход ограничений

**Текущее решение:**
- Использование CORS-прокси (может быть нестабильным)

**Альтернативы:**
- Backend сервер для парсинга
- Browser extension для обхода CORS
- Использование headless браузера (Puppeteer, Playwright)
